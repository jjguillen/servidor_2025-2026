# 🌾 Proyecto: **AgroTrace – Sistema de trazabilidad de productos agrícolas**

## 🎯 Objetivo general

Desarrollar una aplicación web que permita a los agricultores y cooperativas **gestionar lotes de producción**, registrar tratamientos y generar **códigos QR** para que el consumidor pueda consultar la **trazabilidad del producto** (origen, cultivo, tratamientos, fecha de cosecha, etc.).

La aplicación promueve **transparencia, sostenibilidad y seguridad alimentaria**, y puede ser usada tanto por **técnicos agrícolas** como por **consumidores** finales.

---

## 🧩 Funcionalidades principales

### 👤 Roles de usuario

* **Administrador:** gestiona usuarios, cultivos y configuraciones globales.
* **Agricultor:** registra lotes y tratamientos, genera QR para cada lote.
* **Consumidor:** accede a una URL pública (mediante QR) para consultar los datos del lote.

---

### 🌱 Gestión de cultivos y parcelas

* CRUD de **Parcelas** con nombre, ubicación (latitud, longitud), tipo de suelo, superficie, etc.
* CRUD de **Cultivos** (trigo, olivo, tomate, etc.).
* Asociación de cultivos a parcelas.

---

### 📦 Gestión de lotes de producción

* Cada **Lote** representa una producción concreta (por ejemplo, “Tomate Cherry – Primavera 2025”).

* Campos:

  * Código de lote (autogenerado)
  * Parcela
  * Cultivo
  * Fecha de siembra
  * Fecha de cosecha
  * Cantidad producida
  * Estado (en cultivo, cosechado, distribuido)

* Desde la vista del lote se puede **generar un QR** que contenga una URL pública con los datos de trazabilidad.

---

### 💧 Registro de tratamientos agrícolas

* CRUD de **Tratamientos** aplicados a cada lote:

  * Fecha
  * Tipo de producto (fungicida, fertilizante, herbicida, etc.)
  * Nombre comercial
  * Dosis
  * Operario responsable
  * Observaciones

* Los tratamientos se muestran en la ficha del lote (ordenados por fecha).

---

### 🧾 Ficha pública de trazabilidad

* URL pública del tipo:

  ```
  https://agrotrace.test/trazabilidad/{codigo_lote}
  ```
* Mostrará:

  * Datos básicos del lote (cultivo, fechas, ubicación).
  * Tratamientos aplicados.
  * Mapa con la ubicación de la parcela (Leaflet.js).
  * Sello de verificación de la cooperativa.

Ejemplo visual tipo tarjeta:

```
Lote: TOM-2025-001
Cultivo: Tomate Cherry
Parcela: El Olivar Bajo
Ubicación: 37.123, -4.215
Fecha de siembra: 10/02/2025
Fecha de cosecha: 25/05/2025
Tratamientos:
 - 15/03/2025: Fertilizante NPK
 - 05/04/2025: Fungicida (Cobre)
```

---

### 🧾 Exportación y QR

* Cada lote puede generar:

  * **Código QR** con `simple-qrcode` (`composer require simplesoftwareio/simple-qrcode`).
  * **Informe PDF** con `barryvdh/laravel-dompdf`.
* QR enlaza a la vista pública `/trazabilidad/{codigo}`.

```php
use SimpleSoftwareIO\QrCode\Facades\QrCode;

$qr = QrCode::size(200)->generate(route('trazabilidad.show', $lote->codigo));
```

## 🧱 Modelo de datos (Eloquent)

Relaciones principales:

```
User ───< Parcela ───< Lote ───< Tratamiento
      └──< Cultivo
```

**User**

* id
* nombre
* email
* rol

**Parcela**

* id
* user_id
* nombre
* latitud
* longitud
* superficie

**Cultivo**

* id
* nombre
* descripcion

**Lote**

* id
* parcela_id
* cultivo_id
* codigo (único)
* fecha_siembra
* fecha_cosecha
* cantidad
* estado

**Tratamiento**

* id
* lote_id
* fecha
* tipo
* producto
* dosis
* observaciones

---

## 🔄 Relaciones Eloquent

```php
class Lote extends Model
{
    public function parcela()
    {
        return $this->belongsTo(Parcela::class);
    }

    public function cultivo()
    {
        return $this->belongsTo(Cultivo::class);
    }

    public function tratamientos()
    {
        return $this->hasMany(Tratamiento::class);
    }
}
```

## 🌐 Rutas principales

| Recurso              | Controlador              | Rutas                    | Descripción                   |
| -------------------- | ------------------------ | ------------------------ | ----------------------------- |
| Parcela              | `ParcelaController`      | `/parcelas`              | CRUD de parcelas              |
| Cultivo              | `CultivoController`      | `/cultivos`              | CRUD de cultivos              |
| Lote                 | `LoteController`         | `/lotes`                 | CRUD + generación de QR + PDF |
| Tratamiento          | `TratamientoController`  | `/tratamientos`          | CRUD vinculado a lotes        |
| Trazabilidad pública | `TrazabilidadController` | `/trazabilidad/{codigo}` | Vista pública del lote        |

1. **Blockchain / hash de trazabilidad:**
   Guardar un hash SHA-256 del registro del lote para demostrar integridad (solo simulación).

2. **Escaneo móvil:**

---

## 📑 Ejemplo de endpoints públicos (API opcional)

```php
Route::get('/api/trazabilidad/{codigo}', function ($codigo) {
    $lote = Lote::where('codigo', $codigo)->with(['cultivo', 'parcela', 'tratamientos'])->firstOrFail();
    return response()->json($lote);
});
```
